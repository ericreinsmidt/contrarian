# Third-party notices

Contrarian's own code (`src/`, `tools/`, `mk/`, the configs and scripts) is
**0BSD** — see [LICENSE](LICENSE). The pieces below are not.

**No ROMs and no Konami artwork are distributed with Contrarian.** `contra.db`
contains SHA-1 hashes. `contra.fp` contains truncated one-way digests of 1K ROM
blocks — roughly 1KB per base, from which nothing can be reconstructed. Card
faces are captured from the user's own ROMs, on their own device, at runtime.
The boot animation, the television art, the pixel font and all UI graphics are
original work made for this project.

## minarch (`vendor/minarch.elf`, shipped as `Contrarian/minarch.elf`)

Built from [NextUI](https://github.com/LoveRetro/NextUI) source (© the NextUI /
MinUI authors), **GPL-3.0**. Contrarian does not fork NextUI: `minarch/build.sh`
copies a pristine workspace, overlays only the files under `minarch/overrides/`,
and builds in the tg5040 toolchain container.

**Source availability (GPL §6):** the unmodified upstream is the NextUI revision
`minarch/build.sh` is pointed at; Contrarian's modifications are exactly the
diffs in `minarch/overrides/` against it. That directory is currently empty —
the shipped binary is an unmodified NextUI build.

The runtime libraries in `Contrarian/lib/` and the `/.system` resources come
from the same NextUI build and follow its licensing.

## libretro core (`Contrarian/cores/`)

| Core | System | License |
|---|---|---|
| `fceumm_libretro.so` | NES / Famicom | GPL-2.0 |

fceumm is the only core shipped, and it carries no non-commercial restriction —
so unlike a card that also ships snes9x or PicoDrive, a Contrarian card may be
redistributed or sold.

## CRT shaders (`Contrarian/shaders/`)

`contrarian-glow.glsl` and `contrarian-scanline.glsl` are derived from
[Fugazi](https://github.com/ericreinsmidt/nextui-fugazi) (same author), **MIT**.
Constants are re-tuned for Contra; the structure is Fugazi's.

## Font

None. The HUD uses hand-authored 5×7 pixel glyphs compiled into the binary
(`src/font_data.h`, generated by `tools/genfont.py`). No font file is bundled
and no font licence applies.
